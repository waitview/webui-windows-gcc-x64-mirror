# webui-windows-gcc-x64-mirror

Unmodified prebuilt binaries of [WebUI](https://github.com/webui-dev/webui)
for Windows (GCC / MinGW-w64, x64).

- Version: 2.5.0-beta.4 (Nightly Build 2026-09-28 17:24:21 UTC, pre-release)
- Source: `webui-windows-gcc-x64.zip` from the WebUI GitHub releases
- Files are exactly as distributed; nothing has been changed.

This is not the official WebUI repository. For source code, documentation
and support, see https://github.com/webui-dev/webui and https://webui.me.
